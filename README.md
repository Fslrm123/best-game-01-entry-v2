EMBERFALL ARENA — a twin-stick arena survival game. You are the last Ember Warden: hold the arena against the Hollow Star's swarm, gather ember shards, level up and choose upgrades, and slay the boss of wave 10 to win. Keyboard + mouse, sound synthesized in code, no assets, no network.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, aim with the mouse, hold click to fire. P pauses, M mutes, R restarts after a run ends.
